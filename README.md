  - Proforma Invoice (Domestic & Export)
  - Tax Invoice (with GST Breakdown & HSN/SAC)
  - Delivery Challan / Transporter Pass
  - Corporate Letterhead (Official Company Memo)
- **Authentic Brand Design:**
  - Matched with website typography (`Playfair Display`, serif headers)
  - Deep Forest Green (`#003A30`) & Metallic Gold accents
  - Space-saving 4-line footer with location, phone, email, and web
  - Intelligent deduplication of reference & document numbers
- **Authentication & Security:**
  - Login ID & Password protection (Default: `info@mgsupplytech.com` / `MGSupply@2026`)
  - Session persistence with quick auto-fill and credential management in Settings
- **Mac Desktop App (PWA):**
  - Standalone macOS desktop window with Dock icon and offline caching
  - No browser address bar, instant native feel
- **Multi-Bank Management:**
  - Auto-switches between Domestic (NEFT / RTGS / IFSC) and Export (SWIFT / BIC / AD Code / EEFC) accounts
- **Offline & Cloud Sync:**
  - LocalStorage / IndexedDB persistence with optional Firebase Cloud Sync

## 💻 Running on Mac / Local Machine

### 1. Quick Start via Terminal
```bash
# Clone the repository (if not already cloned)
git clone https://github.com/mgsupplytech/MG-SUPPLYTECH-DOCUMENT.git
cd MG-SUPPLYTECH-DOCUMENT

# Install dependencies
npm install

# Start development server
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 2. 1-Click Double-Click Launcher (macOS)
Double-click **`Start-MG-Supplytech.command`** in Finder. It will install packages and boot the server automatically.

## 📱 Installing as Mac Desktop App (PWA)

1. Open the application in **Google Chrome** or **Apple Safari**.
2. **In Chrome:** Click the **Install** icon (`⤓`) on the right side of the address bar ➔ Click **Install**.
3. **In Safari:** Click **File** ➔ **Add to Dock...** ➔ Click **Add**.
4. The app will install into your Mac **Dock** and **Launchpad** with its official emblem.
